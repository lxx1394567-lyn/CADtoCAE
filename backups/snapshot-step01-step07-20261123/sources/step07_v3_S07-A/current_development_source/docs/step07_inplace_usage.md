# Step07 0.8.2：统一六阶段用户入口

使用 `dist/CADtoCAE_Step07_AnalysisSetup/CADtoCAE_Step07_AnalysisSetup.exe`。这是现有 Step07 开发分支上的用户验收构建，尚未合并 main 或发布正式 Release。历史构建保留于 dist/Archive。

## 六安 SP_DC 使用方法

1. 选择 `CADtoCAE-EXE-Testing/Luan`，扫描并选中完整项目编号。
2. 点击“选择当前项目 CAE”。本次核查中，`luan.cae` 没有 Step06 开孔特征；应打开并使用 `SP_DC_ANG19_LUANLUANLUAN-T0203.cae`。EXE 仅记录关联，不读取或启动 Abaqus；PY 在修改前核验当前 Model、装配及开孔特征。
3. 点击生成。七份 PY 和两份工况 JSON 直接位于选定工作目录。日志位于 Step07_Logs。同内容不重写；内容变化须确认并先备份到 Step07_Archive。运行锁或文件被占用时阻断更新。
4. 用户在 Abaqus/CAE 中打开已开孔、没有 Step06 Connector 的模型，先手动保存，再顺序运行 01 Tie、02 Step、03 BC、04 Mesh。每步人工检查、保存。脚本不打开、关闭或自动保存 CAE。
5. SP_DC 只固定 COLUMN_DOWN 的底部。Tie 简化路线不再直接约束实体檩托端部 U2；保留局部檩条两端及基础约束。这是用户已批准的简化。
6. 抱箍—斜撑按本次确认：斜撑对应端部 50 mm 腹板；两半抱箍外侧孔中心局部横向 ±10 mm、完整高度。其他连接仍按实际贴合区域。区域创建通过不代表求解器所有从节点均被有效约束，须继续检查 INP/dat/ODB。
7. 六安当前使用用户授权借用的平塘荷载与 3.7 m 分担长度，标记 DEMO_ONLY；方向使用六安实际 19° 装配法向。它不是六安正式设计工况。不能把该示例映射复制为其他项目通用参数。
8. 在无荷载公共基础模型运行 POS，检查并人工保存；要运行 NEG 必须人工恢复无荷载基础。脚本阻止同一模型叠加两个工况，不自动删除旧 Load。
9. 06 只导出当前工况的独立 INP。风险审核请求绑定模型及荷载指纹，人工填写 TEST_ONLY 许可后才导出；不提交求解。网格 REVIEW_REQUIRED 不会自动变成工程验收通过。

分区和网格清理不可完整回滚。若 01 或 04 失败，请恢复上一次手动保存的模型，勿保存半成品。历史 CAE 不会自动删除。

SP_SC/SP_DC/DP 共用接口，但每套实际输入和荷载仍须分别验收。含旧 Step06 Connector 的 SP_SC 模型会被阻断，不能自动删除连接迁移到 Tie 路线。

# Step07 0.7.3：POS / NEG 独立工况

EXE 只生成 PY/JSON，不启动 Abaqus，不保存 CAE，不提交求解。01～04 的算法保持不变。选择“05 POS/NEG 双工况荷载”及荷载工作簿，会生成两个独立脚本与两个配置；“全部”生成七个 PY（六阶段，第05阶段两份）。

## 手工运行

1. 完成01～04，人工保存**没有荷载**的公共基础 CAE。
2. 运行 `<项目>_step07_05_load_POS.py`，检查四组上翼缘、方向、大小、STEP07_LOADING。人工保存为 POS 模型。
3. 运行 `<项目>_step07_06_inp_export.py`。程序核验当前荷载，生成 TEST_ONLY 许可请求并暂停。阅读风险后，在请求 JSON 中填写 `approved: true`、`reviewed_by`、`reason`，再运行06。许可绑定当前模型网格、对象及荷载配置的指纹。
4. 得到 `M07_J13_POS.inp`（已存在则 `_v2` 等），只写入不提交。TEST_ONLY 不代表网格、Tie 或工程应力正式验收。
5. **人工重新打开无荷载公共基础 CAE**，再运行 NEG，按相同流程导出 `M07_J14_NEG.inp`。

已有任意荷载（含另一工况、同工况或自定义荷载）会阻断05，程序不会自动删除或替换。不要在POS模型中追加NEG。06只接受当前工况完整且未被改动的荷载集合；混合、缺失、额外或更改的荷载阻断导出。

PY 与配置在工作目录，日志在 Step07_Logs。生成器沿用稳定文件名，界面询问覆盖旧脚本；原CAE不动。修改配置后须重新生成脚本以同步SHA256。不要继续运行历史单工况 `load_setup.py`。

## M07 已确认规则

完整项目 DP_ANG14_FA03521S-T0104-02 → 平塘/DP/14°/M07；依据工作簿匹配J13、J14，并交叉校核项目、结构、工程、倾角及工况行。公式缓存缺失时复算，缓存不一致时阻断。

分担长度3.700m，四根檩条：POS每根4630.875896N，合计18523.503584N；NEG带符号每根-3016.7136N，合计-12066.8544N。负号表示与组件内法向相反。以实际装配变换确定方向，通过上翼缘均布面力传给原Tie，不新建RP/Coupling。

## 其他项目

SP_SC、SP_DC、DP 数据接口支持显式项目映射，不按倾角猜测。未提供映射及工程布置时阻断，不套用M07参数。将 `<完整项目>_step07_project.json` 放在 Assembly Summary 同目录，字段为：

- confirmed（true）、source（确认依据）、project_id、model_id、project_site、structure_type、angle_deg。
- support_layout：project_id、model_id、structure_type、purlin_length_m、support_count、support_spacing_m（相邻间距数组）、support_position（LEFT/MIDDLE/RIGHT/SINGLE）、support_index（零起始）、cantilever_left_m、cantilever_right_m、source。

分担长度由实际布置计算，加载实例来自摘要，缺失则停止。M08无模型，只保留原Excel数据，阻断生成可执行配置。其他结构尚未完成本轮真实模型验证。

## 限制

M07的14°体型系数暂借15°；图纸429mm悬挑与总长8.058m矛盾，使用已确认329mm假设。POS按已确认组合标量法向加载，不另加恒雪/重力；NEG仅风吸力。简化Tie、网格质量警告、未匹配Tie节点需独立工程审核。许可仅允许TEST_ONLY导出，不修改原网格报告结论。开发测试使用独立目录及副本，操作与用户脚本隔离。


## 六安网格验证记录（2026-11-01）

新 Tie 选区保持用户确认的 50 mm / 孔中心 ±10 mm。大直径、6 mm 厚实体抱箍沿用 15 mm 加混合边布种时发生低形状质量错误。开发隔离试验确认需一致布种；六安项目内部例外为 HOOP_01 A/B 4 mm、HOOP_02/03 A 6 mm、B 4 mm，第一组 B 及檩托另有局部修复。该例外不作用于 DP、SP_SC 或其他项目，不是收敛性结论。

当前完整装配为 415,133 节点、239,111 单元；强制检查无严重错误，斜梁 45 个一般警告保留 REVIEW_REQUIRED，不能自动认定工程验收。详细单元标签及检查结果位于开发验证目录 luan_080/user_region/Step07_Logs 的 04_run006.json。


## 用户批准的六安试算材料补充

2026-11-01 用户允许仅本轮试算为 MAT_MANUAL_CHECK 补入 E=2.06e11 Pa、ν=0.3。它被后斜撑、下立柱、后立柱引用；不推定牌号、屈服强度或正式工程有效性。06 会在加载/网格预检查后补入缺失的弹性属性，并明确打印及记录。已有弹性属性不会被覆盖。

如果随后因等待 TEST_ONLY 许可而停止，已获批准的材料补充会留在当前 MDB，报告会注明模型已改变；请人工检查后决定保存。脚本不会自动保存 CAE。没有明确配置授权的缺失材料将阻断06，不能靠 TEST_ONLY 许可绕过。
